Germany Demographics: Live Births, Marriages & Population
==========================================================

This project processes official Destatis Genesis-Online datasets for all 16 German
federal states (Bundeslander) from 1990 to 2025, and generates PostGIS-ready SQL
for two separate agent databases.

----------------------------------------------------------
PROJECT STRUCTURE
----------------------------------------------------------

Input files (already in repo):
  live_birth.xlsx          - Live births by state/year (sheet: 12612-0100)
  Marriages.xlsx           - Marriages by state/year (sheet: 12611-0010)
  Population.xlsx          - Population by state/year (sheet: 12411-0010)
  germany_states.geojson   - GeoJSON geometry for all 16 states
  cities_dataset.csv       - German cities with lat/lng and state name

Output files (generated by running the scripts below):
  combined_births_population_marriages.csv  - merged dataset (all states, all years)
  agent1_db.csv                             - Agent 1 subset with missingness applied
  agent2_db.csv                             - Agent 2 subset with missingness applied
  split_metadata.json                       - metadata about the split
  agent1_postgis_db.sql                     - PostGIS init SQL for Agent 1 database
  agent2_postgis_db.sql                     - PostGIS init SQL for Agent 2 database

Scripts:
  build_combined.py             - Step 1: merge Excel files into combined CSV
  split_dataset_agents.py       - Step 2: split combined CSV into agent1/agent2 CSVs
  build_agent1_and_agent2_sql.py - Step 3: generate PostGIS SQL from agent CSVs

----------------------------------------------------------
ACTIVATE THE VIRTUAL ENVIRONMENT
----------------------------------------------------------

A .venv folder is already present in the project directory.

On Windows (PowerShell):
  .venv\Scripts\Activate.ps1

On Windows (Command Prompt):
  .venv\Scripts\activate.bat

On macOS / Linux:
  source .venv/bin/activate

To deactivate when done:
  deactivate

If you need to create the venv from scratch:
  python -m venv .venv
  (then activate as above)
  pip install -r requirements.txt

----------------------------------------------------------
HOW TO RUN EACH FILE
----------------------------------------------------------

Run these scripts in order (each step depends on the previous):

STEP 1 - Build the combined CSV
  python build_combined.py

  Reads:  live_birth.xlsx, Marriages.xlsx, Population.xlsx
  Writes: combined_births_population_marriages.csv

  Merges live births, marriages, and population data into one long-format CSV
  with columns: Land, Year, LiveBirths, Marriages, Population

STEP 2 - Split into agent datasets
  python split_dataset_agents.py

  Reads:  combined_births_population_marriages.csv
  Writes: agent1_db.csv, agent2_db.csv, split_metadata.json

  Partitions the data across two agents with a deliberate missingness pattern
  (some field values are set to NA in one agent but available in the other).

STEP 3 - Generate PostGIS SQL
  python build_agent1_and_agent2_sql.py

  Reads:  agent1_db.csv, agent2_db.csv, germany_states.geojson, cities_dataset.csv
  Writes: agent1_postgis_db.sql, agent2_postgis_db.sql

  Generates idempotent SQL init scripts that create three tables per agent:
    - lands       (land_id, land_name, geo_shape as PostGIS geometry)
    - land_stats  (population + live births per state per year)
    - cities      (point geometries for German cities)

----------------------------------------------------------
LOAD SQL INTO POSTGRESQL (optional, requires PostGIS)
----------------------------------------------------------

After Step 3, load the SQL into a PostgreSQL database:

  psql -d your_db_name -U your_user -f agent1_postgis_db.sql
  psql -d your_db_name -U your_user -f agent2_postgis_db.sql

Requirements:
  - PostgreSQL with PostGIS extension available
  - UTF-8 client/server encoding recommended
